# QAZ DRIVE ACADEMY — 2026

Қазақстан жол жүрісі қағидаларына негізделген қазақ тіліндегі курсанттарға арналған интерактивті оқу сайт-прототипі.

## Бөлімдер
- 17 тақырыптан тұратын теория курсы
- Схемалық жол белгілері
- Three.js арқылы салынатын 3D автодром: дәліз, ирек жол, параллель тұрақ, кері тұрақ, эстакада
- 3D қалалық қиылыс
- 30 авторлық оқу сұрағы және 40 сұрақтық демо сынақ режимі (қайталанатын сұрақтар болуы мүмкін)
- Қозғалыс алдындағы чек-парақ

## Жариялау
1. GitHub-та жаңа public repository жасаңыз (мысалы `qaz-drive-academy`).
2. `index.html` файлын репозиторий түбіріне орналастырыңыз.
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
4. Сайт `https://USERNAME.github.io/qaz-drive-academy/` мекенжайында ашылады.
5. Three.js CDN жүктелетіндіктен интернет керек. 3D көрініс үшін WebGL керек.

## Нормативтік негіз және шектеу
ҚР ІІМ 30.06.2023 №534 бұйрығы, 2026 жылғы өзгерістер ескерілетін ресми жаңартылған нұсқасы: https://adilet.zan.kz/kaz/docs/V2300033003

Бұл білім беру MVP. Барлық тарауды құқықтық мәтін дәрежесінде қайталамайды; 3D жол белгілері схемалық, жаттығу өлшемдері ресми практикалық емтихан схемасы емес. Тесттер ресми емтихан банкінен алынбаған, 40 сұрақ режимі демо (30 сұрақ қайталанады). Емтиханға нақты дайындық үшін ресми деректі және білікті авто-нұсқаушыны пайдаланыңыз.
